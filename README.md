# comp115_project
A simple farm drawing using Python turtle.
This project uses the Python turtle program to create a simple farm drawing, which displays green grass, a red house, a brown roof, a yellow door, and a sun.
#Explanation of how the code works:
With the help of a rectangle function, grass, house, and door are drawn of different sizes and colors. The rectangle drawing is performed through a for loop. The roof and sun are drawn using the goto() and dot() functions respectively.
#How to run the code:
Simply open the “farm.py” in a Python editor like Pythonsandbox, and run the file using turtle mode. The turtle window will show you the drawing made by this project.
